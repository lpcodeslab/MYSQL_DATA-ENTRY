# MYSQL_DATA-ENTRY
A structured SQL project containing the complete employee management database, including tables for employees, departments, and locations with foreign key relationships and sample data inserts.
## ⚙️ Procedure

1. Created the database and tables with the required constraints in Assignment 1.
2. Inserted the provided employee data into the respective tables using DML commands.
3. Retrieved unique salary values using `DISTINCT`.
4. Used `AS` to assign aliases to the age and salary columns.
5. Applied `WHERE` conditions and comparison operators to filter employee records.
6. Identified employees with missing designations and updated the designation to `Data Scientist`.
7. Sorted employee records using `ORDER BY` and displayed limited results using `LIMIT`.
8. Used aggregate functions such as `SUM()`, `MIN()`, `MAX()`, and `AVG()` to perform calculations.
9. Grouped records using `GROUP BY` and filtered grouped results using `HAVING`.
10. Performed `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN` operations to retrieve related information from multiple tables.
11. Executed all queries in MySQL and verified the output against the assignment requirements.

## 📌 Result

Successfully practiced MySQL data querying techniques, including filtering, sorting, aggregation, grouping, updating records, and joining tables.
